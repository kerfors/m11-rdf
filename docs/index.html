A derived rendering of the ICH M11 Technical Specification (Step 4, 2025-11-19), the ICH M11 code lists and OID Listing, and the ICH M11 Terminology published by NCI EVS (release 2025-12-19): one IRI per protocol element, section and code list; the headings and fields of the ICH M11 Template (Step 4, 2025-11-19), each linked to its section and to the element it realises; and mapping statements from the elements to USDM v4 attributes (usdm-rdf), as stated in the HL7 FHIR Clinical Study Protocol IG ballot mapping (May 2026) and the CDISC DDF-RA v4.0.0 M11 mapping. Draft, not normative. Not an ICH, CDISC or HL7 artifact, and not endorsed or sponsored by ICH.
