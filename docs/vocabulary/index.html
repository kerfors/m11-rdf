Vocabulary

The terms m11-rdf defines, from vocabulary.ttl (also merged into m11-rdf.ttl). Other terms on these pages come from SKOS, RDFS, RDF, OWL and Dublin Core. Grouped by type (rdf:type).

Classes (10)

Kinds of things. Each class page links to its instances.

TermNameDescription
Basism11:BasisWhere a statement in this graph comes from.
Code listm11:CodeListAn ICH M11 code list with an ICH OID. Local name = its C-code.
Conformance categorym11:ConformanceCategoryRequired, Optional or Conditional: the first word of the Technical Specification conformance statement. The statement itself is kept verbatim in m11:conformance.
Elementm11:ElementAn ICH M11 protocol element: a concept within a namespace, identified by the (namespace code list, concept C-code) pair the Technical Specification states. Local name <namespace code list>.<concept code>.
Namespacem11:NamespaceOne of the 16 M11 namespaces (OID arc 2.16.840.1.113883.3.989.2.3.3): the section code list that elements belong to.
Sectionm11:SectionA section of the ICH M11 protocol, identified by its term in code list C217272 (Protocol Section Name and Number). Local name C217272.<term code>.
Specificationm11:SpecificationWhat one component block of Technical Specification Appendix 1 states about an element: place, conformance, cardinality, data type, value code list. An element specified in several blocks has several specifications; a block with alternative concepts is one specification shared by those elements.
Template fieldm11:TemplateFieldA text insertion point (<...>) or controlled-terminology pick ([...]) in one section of the ICH M11 Template (Step 4, 2025-11-19), outside instructional text. A blank node on its section, not identified by an IRI.
Template field kindm11:TemplateFieldKindThe Template convention a field follows (Template section 0.3).
Value code listm11:ValueCodeListAn M11 code list of response values (OID arc 2.16.840.1.113883.3.989.2.3.1).
